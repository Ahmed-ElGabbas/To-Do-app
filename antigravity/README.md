## Firebase setup

The following files are generated by the FlutterFire CLI and are gitignored:
`lib/firebase_options.dart` (staging, the local default),
`lib/firebase_options.production.dart`, `android/app/google-services.json`, and
`ios/Runner/GoogleService-Info.plist`. Do not commit them; regenerate them with:

```
flutterfire configure --project=tasko-staging --platforms=android,ios --android-package-name=com.tasko.app --ios-bundle-id=com.tasko.app --yes
flutterfire configure --project=tasko-production-14179 --platforms=android,ios --android-package-name=com.tasko.app --ios-bundle-id=com.tasko.app --yes --out=lib/firebase_options.production.dart
```

Run the staging command last so the platform config files on disk point at
`tasko-staging`. The values are non-secret (Firebase's own security boundary is
server-side rules and App Check); they are gitignored only for consistency with
this project's "nothing environment-specific gets committed" convention.
